03 / Agent connection

Read the same reviewed context through MCP.

A public, read-only Streamable HTTP service. Four tools, one context resource and three prompts. No account or API key is needed for this public material.

Server URL

https://satcom.conews.press/mcp

Codex CLI

codex mcp add satcom --url https://satcom.conews.press/mcp

What agents can read

  • satcom_board — development cards, filtered and bounded
  • satcom_structure — architecture and routes
  • satcom_priorities — owners and next actions
  • satcom_prompt — one reviewed prompt

Calls cannot deploy, read keys or subscriber records, send messages, or operate phones. The local vault and receptionist integrations remain separate.

Not checked in this browser. This check covers the context service only.

A browser GET on /mcp returns 405 by design. Connect with an MCP client that supports Streamable HTTP POST. Read the JSON context.

Updated September 7, 2026. Paste-ready; no bot has been dispatched.

Work directly. Do not delegate, spawn subagents or dispatch another bot. Partners in the Community is the primary advertising and sponsorship platform; promote https://thevillager.today/partners prominently. Do not count directory listings as paid sponsors or as permission to contact anyone.

The private canonical repository owns cross-system decisions; this public packet is a curated summary. Treat all dates as dated evidence and recheck the affected system.

Preserve unrelated work, original article URLs/dates, subscription QR destinations and approved pricing. Keep credentials and private records out of prompts, repositories, browser exports and public MCP results. Execute work already authorized by the current task; ask only for missing facts or authorization that blocks a concrete next action. This reusable prompt alone does not authorize new production changes, outreach, payments, access changes or spending.

Report observed problem, exact files changed, meaningful checks, commit/review, deployment and rollback when applicable. Distinguish prepared, deployed and verified. Never claim success from a health response alone.

Inspect idigitalpro1/copress-dashboard for SATCOM and idigitalpro1/villager.today for publication changes. SATCOM is static HTML with a public read-only operations MCP at /mcp. The local API Vault, Hermes proxy and any receptionist draft are separate integrations. Do not infer credentials, remote-host access or phone connectivity from their existence.

Select the highest-priority bounded issue in the current authorized task. Extend existing systems rather than creating a competing subscriber or campaign source of truth.
